# 슬랙 스킬 등록용 (짧게)

🎤 **공유회-OS** — 1시간 발표를 주제부터 발표 대본까지

주제 막막해도 OK. 대화 기록 훑어 발표거리부터 깔아줍니다.
질문 3개 → 제목 → 목차 → 웹 슬라이드 → 발표 대본 → 검수.
발표자 노트·타이머 내장 · 인터넷 링크로 바로 공유.

⚠️ Claude Code(터미널) 전용 — claude.ai 웹·앱 채팅에서는 안 돼요. 터미널에서 `claude` 열고 쓰세요.

**설치**
```
git clone https://github.com/Koo-bon/skillers-share.git
cd skillers-share && bash install.sh
```
**호출**: `공유회 준비해줘`
