## 새 컴퓨터에서 (3단계)

```bash
# 1) 받아서 설치
git clone https://github.com/Koo-bon/skillers-share.git
cd skillers-share && bash install.sh

# 2) 잘 붙었는지 검사
bash verify.sh          # PASS 나오면 됨

# 3) 표지 시안 눈으로 보기
python3 design-concepts/serve.py    # → localhost:8931
```

- `git` 이 없다고 나오면 맥은 `xcode-select --install` (몇 분)
- **고치는 건** 이 클론 폴더에서. 고친 뒤 `bash install.sh --force` 로 다시 깔고 테스트합니다
- 커밋은 `git add -A && git commit && git push`

### 최근에 고친 것

- **표지 두 줄이 겹치던 버그** — `line-height:.88` 이 문제. 한글 볼드는 받침이 베이스라인 아래로 내려옵니다. `.96` 으로
- **아웃라인 표지에서 제목이 통째로 안 보이던 버그** — `-webkit-text-stroke` 에 `currentColor` 를 쓰면 바로 위 `color:transparent` 를 물려받아 테두리까지 투명해집니다. 색을 직접 줘야 합니다

- **`install.sh` 가 `build-deck.sh`·`deploy.sh` 를 안 옮기던 것** — 클린룸 클론 테스트로 발견. SKILL.md 는 그 스크립트를 부르는데 설치하면 없었습니다

## 자주 밟는 지뢰

| 증상 | 원인 |
|---|---|
| 덱이 통째로 하얗게 뜸 | `ending` 슬라이드에 `lines` 가 없음 → `undefined.map`. 브라우저 콘솔에 나옵니다 |
| 대형 타이포 색이 다 똑같음 | `<!doctype html>` 누락 → 쿼크스 모드 → 클래스 이름 대소문자 구분이 사라져 `.f` 와 `.F` 가 충돌 |
| 밝은 테마인데 배경이 검정 | webdeck 자체 다크 배경이 이깁니다. `!important` 로 덮어야 합니다 |
| 발표자 노트가 엉뚱한 장을 보여줌 | webdeck 은 스크롤이 아니라 **페이지형**. `.slide.active` 를 따라가야 합니다 |
| `deploy.sh` 가 레포 이름을 이상하게 만듦 | 제목이 날짜로 시작하면 잘립니다. `SAFE` 처리 로직 확인 |
