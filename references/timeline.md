# 1시간 배분

공유회는 1시간이다. **혼자 1시간은 슬라이드만으로 못 버틴다** — 발표자도 청중도.

## 데모가 있을 때 (기본)

| 시간 | 구간 | 슬라이드 |
|---|---|---|
| 0–5 | 도입 — 내가 뭐에 막혔나 | 3~4장 |
| 5–20 | 본론 전반 | 7~9장 |
| 20–35 | 본론 후반 | 7~9장 |
| **35–50** | **라이브 데모** | 2~3장 (전환용) |
| 50–60 | Q&A + 따라하기 | 3~4장 |

구간 경계: `0 / 5 / 20 / 35 / 50 / 60`

**35–50분이 1시간을 버티게 한다.** 실제로 돌아가는 걸 보여주는 구간이 있으면 앞뒤가 훨씬 가벼워진다.

## 데모가 없을 때

| 시간 | 구간 | 슬라이드 |
|---|---|---|
| 0–5 | 도입 | 3~4장 |
| 5–20 | 본론 전반 | 7~9장 |
| **20–30** | **환기 — 질문 던지기 또는 짧은 실습** | 2~3장 |
| 30–45 | 본론 후반 | 8~10장 |
| 45–60 | Q&A + 따라하기 | 4~5장 |

구간 경계: `0 / 5 / 20 / 30 / 45 / 60`

**20–30분 환기 구간을 반드시 넣는다.** 슬라이드만 45분 연속은 중반에 무너진다. 청중에게 질문을 던지거나 짧게 같이 따라 해보게 한다.

## 유형별 본론 배분

| 유형 | 본론 전반 | 본론 후반 |
|---|---|---|
| 만든 것 보여주기 | 왜 만들었나 · 구조 | 막힌 곳 · 지금 쓰는 법 |
| 툴 사용법 전수 | 결과물 · 기본 사용법 | 내가 찾은 요령 · 한계 |
| 입문 기초 | 개념 3개 | 눈으로 확인 · 흔한 오해 |
| 삽질기 | 목표 · 1차 실패 | 2·3차 시도 · 풀린 지점 |
| 본업 전문성 | 사람들이 틀리는 것 | 내 방식 · 사례 |
| 작업 흐름 전체 | 원래 흐름 · 대체 지점 | 이어 붙일 때 문제 · 완성 흐름 |

## 슬라이드 장수

**1시간 25~35장. 한 장에 평균 2분.**

- 도입·전환 슬라이드는 10~20초 — 장수에 넣되 시간은 거의 안 먹는다
- 본론 슬라이드는 2~4분 — 여기서 시간이 나간다
- **40장을 넘으면** 넘기기 바빠 설명이 얕아진다
- **20장 밑이면** 한 장에 5분 이상이라 청중이 지친다

## 소재를 2~3개 엮을 때

1시간이면 소재 하나로는 얇을 수 있다. **엮을 때는 유형을 하나로 통일한다.** 소재는 여럿이어도 유형이 흔들리면 발표가 산만해진다.

예: 소재 3개를 전부 `작업 흐름 전체` 관점으로 — "내 업무 흐름 세 군데를 어떻게 이어 붙였나"
